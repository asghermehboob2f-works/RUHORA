# ROO / Creative Studio — Ultra-Premium Digital Experience Master Prompt

## 01 — THE PRIMARY OBJECTIVE

Build an extraordinary, world-class digital experience for a premium creative editing, post-production and AI visual production studio.

Working brand name:

**\[BRAND NAME]**

The brand name is temporary and must be globally replaceable through one configuration/site-setting rather than being hardcoded throughout the application.

This is **NOT** a normal portfolio website.

It is **NOT** a freelancer website.

It is **NOT** a generic creative-agency template.

It is **NOT** a SaaS landing page.

It is **NOT** an "AI agency" website covered in gradients.

It must feel like a **digital flagship for an elite creative production studio**.

The interface should be so carefully art-directed, polished and original that visitors immediately understand:

> This studio operates at an unusually high level.

The goal is to create an experience that feels:

**Cinematic  
Editorial  
Luxury  
Minimal  
Technological  
Experimental  
Precise  
Confident  
Immersive  
Human  
Extremely refined**

Do not attempt to communicate premium quality by simply adding more effects.

Premium quality must come from:

**composition + typography + spacing + imagery + motion + interaction + restraint + technical execution.**

Every pixel should look intentional.

\### Typography



Use free, self-hosted (via `next/font`) fonts by default, behind a single `config/fonts.ts` so a licensed pair can be swapped in later (e.g. Neue Montreal + PP Editorial New) without touching components.



\- \*\*Display:\*\* Instrument Serif (regular + italic). Tight tracking (-0.03em), line-height 0.9–0.95. Italic used for a single emphasised word per headline, never whole headlines.

\- \*\*UI / body:\*\* Inter Tight (or Geist). Body 16–18px, line-height 1.55, max 62ch.

\- \*\*Metadata / labels:\*\* Geist Mono, 11–12px, uppercase, tracking +0.08em.



Type scale (fluid with `clamp`, defined once):



```

display     clamp(3rem, 7vw, 8rem)

h2          clamp(1.75rem, 3vw, 3rem)

h3          clamp(1.25rem, 1.6vw, 1.75rem)

body        1rem

caption     0.875rem

meta        0.6875rem mono uppercase

```



The contrast between `meta` and `display-xl` on the same screen is the signature. Never use display sizes for ordinary sections.



\### Spacing, grid, shape



\- 4px base unit; scale: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128, 192, 256.

\- Section vertical rhythm: 128px (mobile 80px) minimum between major sections; some sections deliberately get 256px of silence.

\- 12-column grid, 24px gutter (16px mobile). Page max-width 1680px; \*\*ultra-wide (≥1920px)\*\*: content stays centred at max-width, full-bleed media may extend but text never does.

\- \*\*Radius:\*\* 0 by default. 2px on inputs only. No pill buttons, no rounded cards. Sharp edges are part of the look.

\- Borders are 1px hairlines. No box-shadows except one soft shadow on menus/modals.



\### Motion tokens



```

```



Animate only `transform`, `opacity`, `clip-path` and `filter` (sparingly). Never animate layout properties. Target 60fps on a mid-range Android phone.

\## 4. MOTION \& INTERACTION SYSTEM



\- \*\*One library for scroll choreography:\*\* GSAP + ScrollTrigger, dynamically imported, client-only, used only in components that need it. \*\*Lenis\*\* for smooth scroll, disabled when `prefers-reduced-motion` is set, on touch if it hurts native feel, and inside modals.

\- Everything else (hovers, focus, small reveals) is \*\*plain CSS\*\*.

\- \*\*Budget:\*\* at most one "hero-level" motion in the viewport at any time. Text reveals are masked line-by-line (translateY within overflow-clipped lines), never letter-by-letter confetti.

\- \*\*Cursor (desktop, fine pointer only):\*\* a 8px dot that expands into a small label pill (`VIEW`, `PLAY`, `OPEN`, `DRAG`) over interactive media. Never a giant circle. Uses `transform` via a single rAF loop. Fully disabled on touch and reduced-motion.

\- \*\*Links/buttons:\*\* text links get a directional underline that wipes in from the side the pointer entered. Primary CTA is a rectangular button with a text-swap hover (label slides up, duplicate slides in) — no gradient, no glow.

\- \*\*Page transitions:\*\* a fast (≤ 700ms) clip-path wipe using the View Transitions API where supported with a graceful fallback. Never block navigation on animation; never re-run the loader on route change.

\- \*\*Loader:\*\* shown only if assets are genuinely not ready. Brand mark + hairline progress, max \~1.2s, skipped entirely on repeat visits (session flag) and when ready sooner.

\- \*\*Reduced motion:\*\* no parallax, no scroll-linked transforms, no cursor, no letterbox animation, no autoplaying video (poster shown with a play button). The site must be fully usable and still look designed.

\## 5. SIGNATURE COMPONENTS (build these with care; everything else follows from them)



\### 5.1 Hero — "Opening Frame"

\- Fills the viewport (`100svh`). Media dominates; typography sits on top with mix-blend or a scrim — choose whichever keeps contrast ≥ 4.5:1.

\- Sequence (≤ 1.6s total): letterbox bars retract → media resolves → headline lines mask-reveal → meta row (location, timecode ticking, "Scroll") fades in.

\- Layout: tiny meta top-left/right, massive headline bottom-left, media behind/within. Extreme scale contrast is the point.

\- Media: HLS/MP4 muted loop with poster; controls for play/pause, sound (default muted, never autoplay audio, remember preference), fullscreen. Mobile: poster + short vertical or cropped loop; no heavy video on slow connections (`navigator.connection.saveData`).

\- If no video is supplied: use the \*\*Media Placeholder\*\* (5.2), never stock footage.

\- Headline copy: generate 3 original candidates following section 8, present them, and put the chosen one in SiteSetting.



\### 5.2 Media Frame \& Placeholder

A single `<MediaFrame>` component used everywhere: respects `ratio` prop, lazy loads, shows poster/blurhash, handles hover-preview video, optional crop marks and timecode. Its \*\*placeholder state\*\* (no media yet) renders a sunken frame with crop marks, a running timecode and the label `MEDIA PENDING — 16:9`. This is the only "fake" visual allowed and it is obviously a placeholder.



\### 5.3 Featured Work — "The Reel"

Three to five featured projects, each a near-full-viewport scene with its own composition (full-bleed 16:9, 90% asymmetric, a vertical 9:16 story beside big type, a split screen). Scenes are joined by \*\*cuts\*\* (clip-path wipe driven by scroll), not fades. Each shows: index as timecode, client, category, title, `VIEW CASE STUDY →`. Layout is chosen per project from its `layoutVariant` field, so the CMS controls the rhythm.



\### 5.4 Project Index

A typographic list (large titles, mono metadata) rather than a card grid. Hover a row: title shifts, a preview video follows the cursor (or docks at the side), index counter animates, cursor becomes `VIEW`. Filters (Category / Format / Year / Capability / Client) are inline text toggles, not dropdown-heavy ecommerce chrome. Lightweight search opens as a command-style overlay (`/` shortcut). On mobile: vertical cinematic stack, tap to preview, tap again to open.



\### 5.5 Before / After Scrubber

Draggable and keyboard-accessible (`role="slider"`, arrow keys, Home/End), pointer-capture based, synchronised playback for video pairs, handle is a hairline with a timecode label. Labels `RAW` / `FINAL`.



\### 5.6 Capabilities — "The System"

An index list (Video Editing, AI Video, AI Visuals, Short-form, Long-form, Interviews, YouTube, Commercial, Motion, Post-production, Visual Storytelling). Selecting one swaps a right-hand panel: description, deliverables, related projects, example media. The \*\*AI Production\*\* part is a distinct chapter: Generative Video · Generative Imagery · AI-assisted Storytelling · Concept Development · Hybrid Production. Tone: \*AI expands what can be made; taste decides what is kept.\* No robot/brain/sparkle imagery, no gradients.



\### 5.7 Process

Five stages — Understand, Concept, Build, Refine, Deliver — as a horizontal-on-desktop / vertical-on-mobile sequence. Activating a stage swaps the supporting media/text. Copy is specific to how this studio actually works (supplied by admin).



\### 5.8 Creative Directory

Portrait-led, list-first layout (name, role, specialisation), expanding to bio, skills, selected work, socials. Roles: Editor, Creative Director, Motion Designer, AI Artist, Colourist, Sound Designer, Producer. CMS-driven; empty state is tasteful.



\### 5.9 Inquiry — "The Slate"

Structured intake: Name, Email, Company/Creator, Project Type, Budget, Timeline, Deliverables, Reference Links, Description, File Upload, Communication Preference. Styled as a slate; multi-step optional but must be one accessible form underneath. Every field has default / focus / filled / error / disabled states; submit has loading → success/failure. Success message: \*\*"We received your project."\*\* — no response-time promise unless configured in SiteSetting.



\### 5.10 Footer — "Closing Frame"

A huge closing statement, then WORK / STUDIO / CAPABILITIES / CONTACT / SOCIAL / LEGAL, then brand info. Everything from SiteSetting/NavigationItem.
